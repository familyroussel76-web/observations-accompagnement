OBSERVATIONS MOBILE — PUBLICATION GITHUB PAGES

1. Créer un dépôt GitHub, par exemple : observations-accompagnement
2. Décompresser ce ZIP.
3. Envoyer à la RACINE du dépôt :
   - index.html
   - manifest.webmanifest
   - service-worker.js
   - le dossier icons
4. Dans GitHub :
   Settings > Pages
   Source : Deploy from a branch
   Branch : main
   Folder : /(root)
   Puis Save.
5. Attendre la publication. GitHub affiche l'adresse du site, par exemple :
   https://VOTRE-NOM.github.io/observations-accompagnement/
6. Sur Android, ouvrir CETTE ADRESSE dans Chrome.
7. Menu Chrome ⋮ > Installer l'application
   (selon la version de Chrome : « Ajouter à l'écran d'accueil » peut être affiché à la place).

IMPORTANT
- Ne pas ouvrir index.html depuis le dossier Téléchargements : l'installation PWA ne sera pas proposée.
- Les données de l'application restent dans le stockage local du navigateur/appareil.
