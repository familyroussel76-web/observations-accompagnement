MISE À JOUR V12 — GITHUB PAGES

Sur le dépôt observations-accompagnement :

1. Cliquez sur + > Upload files.
2. Déposez au minimum :
   - index.html
   - manifest.webmanifest
   - service-worker.js
3. Cliquez sur Commit changes.
4. Attendez que le déploiement GitHub Pages soit terminé.
5. Sur Android, fermez puis rouvrez l'application.
6. Si nécessaire, actualisez une fois.

Les observations déjà enregistrées sur le téléphone ne sont pas effacées :
la clé de stockage locale reste identique.
