CORRECTION GITHUB PAGES

Tous les fichiers doivent rester à la racine du dépôt.

Pour corriger le dépôt existant :
1. Add file > Upload files
2. Envoyer index.html, manifest.webmanifest et service-worker.js
3. Laisser GitHub remplacer les fichiers portant les mêmes noms
4. Commit changes
5. Attendre le nouveau déploiement
6. Sur Android Chrome, fermer l'ancien onglet puis rouvrir l'adresse du site
7. Actualiser la page
8. Menu ⋮ > Installer l'application
